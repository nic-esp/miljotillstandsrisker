Frames within each image have their own six-step sequence. Those frame numbers are not the option numbers.

The confirmed interface is read-only browsing and investigation; record preparation happens upstream. New control IDs, split actions and branch mappings are illustrative proposals. The storyboards are for reviewing layout and interaction; their generated small text, incidental labels and counts are not a canonical dataset or legal review. Implementation must use the actual record IDs, process labels, source evidence and reviewed mappings from the repository. In particular, date monitoring is not a preventive barrier and a linked control does not establish implementation or effectiveness.
